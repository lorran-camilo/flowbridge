# Comunicação do FlowBridge no LinkedIn

Esta pasta organiza a comunicação pública do FlowBridge como um projeto de aprendizado em andamento. O foco é contar descobertas, decisões e resultados que possam ser demonstrados, não apresentar uma aplicação em planejamento como se já estivesse pronta.

## Como usar

1. Consulte [CONTENT_PLAN.md](CONTENT_PLAN.md) para temas e momentos com potencial de publicação.
2. Ao concluir uma fase, use [PHASE_UPDATE_TEMPLATE.md](PHASE_UPDATE_TEMPLATE.md) para reunir evidências antes de redigir um post.
3. Atualize [PROGRESS_LOG.md](PROGRESS_LOG.md) somente com fatos observados no código, testes realmente executados, documentação e Git quando disponível.
4. Registre conceitos no [LEARNING_LOG.md](../../learning/LEARNING_LOG.md) como estudados ou compreendidos apenas com base no que o proprietário confirmar; separar explicação recebida de domínio demonstrado.
5. Salve cada rascunho em `posts/NN-slug.md` e siga [VISUAL_GUIDELINES.md](VISUAL_GUIDELINES.md) para materiais visuais.
6. Apresente o texto e a imagem sugerida ao proprietário para revisão e aprovação. Não publique automaticamente.

## Regras editoriais

- Diferencie com clareza **planejado**, **em desenvolvimento**, **implementado** e **validado**.
- Não invente funcionalidades, números, cobertura, resultados de testes, desafios ou aprendizados pessoais.
- Antes de escrever uma atualização de fase, confira o código, executeções de teste registradas/efetivamente executadas e diffs/commits disponíveis. Se Git não existir, anote essa limitação.
- Descreva uso de IA de forma transparente: ferramenta de apoio didático e técnico; o proprietário conduz o trabalho e é responsável por estudar, revisar, testar, validar e compreender as soluções.
- Nunca alegue que todo o código foi escrito manualmente pelo proprietário.
- Não inclua credenciais, tokens, dados pessoais, imagens privadas ou detalhes confidenciais.
- Um post deve compartilhar aprendizado relevante ou resultado demonstrável. Não é necessário publicar a cada tarefa ou commit.
